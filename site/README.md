Private browser-based 3D model inspection tool for Silverhart Saga 3D.

The model selector includes the Ara base/equipment previews and the first Hollowmere village cast. Selecting a Hollowmere character loads the exact GLB generated from that character's saved Ara profile. The profile panel reports the Ara gender, age, height, weight and muscularity sliders, eye colour, hair, tattoos, clothing, accessories and export detail.

The Hollowmere models are generated from the repository's pinned Ara build and are copied into this Space by the Wren Workshop publish workflow. They are previews of the authored NPC profiles, not live editable sliders: changing appearance requires editing the profile JSON and rebuilding the Ara GLB.
