# Dragon source assets

Place original dragon GLB/GLTF source models in this folder. Keep source files
unchanged and register each model once in
`scripts/creatures/creature_asset_catalog.gd`.

The first registered model is expected at
`ashwing_drake_lite.glb`, copied from the supplied
`Ashwing_Drake_Lite.glb`. Use Git LFS for this large source model when adding
it from a local clone; do not commit a pointer without uploading the LFS object.
Record the source URL and licence/usage terms before distributing a public build.
